Step 1 — Create a folder and go there
>mkdir C:\omniroute-docker
>cd C:\omniroute-docker

Step 2 — Create .env in that same folder
>C:\omniroute-docker\.env

Step 3 — Run the command from that folder
>cd C:\omniroute-docker

This is for installing omniroute in docker desktop --> docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 --env-file .env -p 20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest


Step 4 (optional):- Confirm the container is up

>docker ps
You should see omniroute with status Up.

After it starts
Open in your browser:

http://localhost:20128

Useful commands later
Stop ->    docker stop omniroute
Start again -> docker start omniroute
View logs -> docker logs -f omniroute
Update to newer image -> docker pull diegosouzapw/omniroute:latest then recreate the container

Below are the instructions for setting up OmniRoute:

1. Connect the free-tier providers.
2. Create a combo and name using "auto/omniroute", then select all the free models from the providers you have connected.
3. Generate an API key and enable all available permissions/options.
4. Go to Endpoints, then copy the endpoint URL(http://localhost:20128/api/v1) and the API key from the API Keys section.
5. Configure your Java application by using the copied endpoint URL and API key in your IDE or project configuration.
